# Server Fan, Power Supply and Cover Installation

Source: written from the action definitions (actions.json, actions 1-9) in the NVIDIA SOP Monitoring Blueprint sample data "sop-server-fan-installation-data" version 1.0-260213. This is a demo procedure for PraxiProof, not an official NVIDIA service manual.

## Scope

This procedure installs six fans, two power supplies and the server cover. Perform the steps in the numbered order.

## Procedure

1. Install the six fans one at a time. For each fan, connect the fan connector first, then press the fan in place.
2. Install the first power supply. Place the power supply in its compartment, then firmly press it in its place until the latch clicks.
3. Install the second power supply the same way. Place it in its compartment, then firmly press it in its place until the latch clicks.
4. Install the server cover. Place the cover in its shown location on top of the server, then press the black latch to lock the cover in place.

## Requirements

- All six fans must be installed.
- Both power supplies must be installed.
- Install the fans before installing the power supplies.
- Install the power supplies before installing the server cover.
- The server cover must be installed and locked with the black latch.
